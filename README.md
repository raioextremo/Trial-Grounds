Description
Trial Grounds is an asymmetric multiplayer horror experience for Minecraft Bedrock.

One player becomes the Killer. The others are Survivors.
Survivors repair generators under pressure, avoid the terror radius, and try to power the exit gates. The Killer downs, carries, and hooks survivors to end the trial.

Features:
• Generators with skill checks
• Meat hooks and rescue gameplay
• Carry, struggle (A/D), and hook stages
• Killer bloodlust and survivor terror effects
• Jumpscares, atmosphere, and street-lamp lighting tied to generators

Status: Early beta expect balance and bug fixes. Requires friends in the same world; best with 2–5 players.

Not affiliated with any other commercial horror game.
